# 秘密偶像公主圖鑑 GitHub 版本

這是一份可直接更新到 GitHub repository，並部署到 GitHub Pages 的前端版本。

## 內容

- `index.html`
- `style.css`
- `app.js`
- `cards.json`
- `cards-data.js`
- `manifest.json`
- `service-worker.js`
- `icons/`
- `images/`
- `.nojekyll`
- `ui-materials-apply-ready/backgrounds/header_bg_strip.png`

## 特點

- 純前端，不需要後端
- 可部署到 GitHub Pages
- 支援 PWA 安裝
- 收藏資料保存在瀏覽器 `localStorage`

## 本機預覽

建議用靜態伺服器開啟，不要直接雙擊 `index.html`：

```bash
npx serve .
```

## 部署到 GitHub Pages

請看同資料夾內的 `DEPLOY_GITHUB_PAGES.md`。
